01 Purpose

The corpus deliberately contains overlapping topics, named-entity traps, tables, different paper lengths, and conflicting findings.

Those properties make retrieval quality visible. A useful answer must identify the right species, method, intervention, and result instead of matching the word “aging.”

02 Contents

The 27 papers cover mechanisms of aging, epigenetic clocks, biomarkers, senescence, geroprotectors, and mathematical models of mortality.

Papers 021 through 027 contain displayed equations. They are the test set for whether the selected PDF parser preserves scientific notation.

The complete paper list, licences, source identifiers, page counts, and retrieval challenges are in the corpus manifest.

03 Reproduce

The repository includes the full corpus. Run this command only to restore or refresh it from source:

uv run scripts/fetch_corpus.py

The downloader fetches the publisher PDFs from Europe PMC, checks the PDF header and file size, and extracts text from every page.

The PDFs are stored in data/corpus/longevity/ and tracked in Git so a reviewer can run ingestion without a long first download.

04 Provenance

Every document is in the PubMed Central Open Access subset and carries a Creative Commons licence.

The downloader pins each paper by its PubMed Central ID. It does not bypass paywalls.
