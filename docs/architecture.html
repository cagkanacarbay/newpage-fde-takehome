02 One product, one image, two durable data paths

Next.js gives researchers the chat and PDF interface. FastAPI serves chat, documents, and server-sent events.

03 Build the index from the paper corpus

Ingestion turns each source PDF into contextual chunks, vectors, lexical text, and citation geometry.

04 Plan, retrieve, rank, answer, verify

The request path uses different query forms for semantic meaning and exact scientific terms, then limits the answer to packed evidence.

05 Every citation returns to its PDF evidence

The system preserves source geometry from parsing to the highlighted paper page. It does not create citations after generation.
