01 PDF parsing: Docling

Use Docling to parse the research corpus. Keep MinerU only as a reproducible comparison baseline.

TL;DR

What: Parse every source PDF with Docling and HeadingHierarchyOptions(enabled=True).

Why: Docling preserves page metadata and the key table, provides usable heading depth, runs locally, is MIT licensed, and was 40 times faster than MinerU on paper 014. Research evidence.

Status: Provisional. Formula support and node-level page provenance still need direct tests. Open research.

How we use Docling

Enable heading hierarchy on every parse

Pass HeadingHierarchyOptions(enabled=True).

Default Docling output makes every heading level 1. The option restores usable nested headings without another dependency. Research evidence.

Keep page provenance through the node layer

Keep page_no from parser output through LlamaIndex nodes before we offer page-level citations.

Docling emitted page data for every measured item. Whether DoclingReader retains it in node.metadata remains untested. Research evidence.

Fail ingestion when parsing returns no content

Reject an empty parser result even if the process exits successfully.

Docling can exit without output under a restrictive sandbox. Research evidence.

Do not hide known Docling defects

Paper 011 has a reading-order error. Paper 009 has two unbound table captions and one duplicated caption.

Do not add a repair until a regression test proves it. MinerU output is the comparison reference for both cases. Research evidence.

Use MinerU only as the comparison baseline

Do not add MinerU to the application ingestion path.

MinerU preserves paper 011 reading order and table captions. It emits no heading level deeper than 2 and took 453.4 seconds where Docling took 11.4 seconds. Research evidence.

Revisit the choice only after the remaining tests

Run both parsers on papers 021 through 027 before deciding formula support.

Reconsider Docling if MinerU preserves equations where Docling does not, if MinerU adds deeper headings, or if Docling regresses on hierarchy. Test Kreuzberg only if a material gap remains. Research evidence.
